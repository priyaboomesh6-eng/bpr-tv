➕ Ulla Eathi Eppadi Add Pantrathu?
1. Mela irukka + Add Channel button ah click pannu
2. Channel Name podu - Ex: En Songs
3. YouTube Link podu - Ex: https://youtu.be/aqz-KE-bpKQ
4. Odane pudhu Channel CH 105, 106... nu add aayidum! ✅

🗑️ Delete Pantrathu? Channel card la ✕ ah click pannu
👥 Mathavanga Eppadi Paakkuranga?
1. Un website ah Netlify / GitHub Pages la FREE ah podu
2. Aprom 🔗 Share button ah click pannu - Link copy aagum
3. Andha link ah WhatsApp / Instagram la friend ku anuppu
4. Avanga link ah click panna - Guest ah paakalaam! Password theva illa! ✅

Example Link: https://bpr-tv.netlify.app/?ch=101
